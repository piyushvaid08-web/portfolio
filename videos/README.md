## Supported Video Formats

1. **Local MP4 / WebM**:
   - Format: `.mp4` (H.264 or H.265 / AAC audio) or `.webm`
   - Recommended resolution: 1080p (1920x1080) or 4K (3840x2160)
   - Max file size recommended for web: 15MB - 40MB for fast buffering

2. **YouTube & Vimeo Embeds**:
   - If your videos are hosted on YouTube or Vimeo, you don't even need to upload large files!
   - Just change the `data-video-src` attribute on any button or card in the HTML files to your YouTube/Vimeo URL:
     ```html
     data-video-src="https://www.youtube.com/watch?v=YOUR_VIDEO_ID"
     ```
     or
     ```html
     data-video-src="https://vimeo.com/YOUR_VIDEO_ID"
     ```

## How It Works

- Every video thumbnail card has a hover play overlay.
- Clicking any **"Watch Film"**, **"Watch Video"**, or thumbnail automatically opens the high-performance cinematic lightbox modal.
- If a local video file has not been copied to this folder yet, the player automatically provides a button to preview with a demo luxury reel so your portfolio never looks broken.
